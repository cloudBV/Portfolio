## Featured Games

Classic games reimagined with original mechanical twists. All playable in the browser at [cloudbv.itch.io](https://cloudbv.itch.io/).

| Project | The Twist |
|---|---|
| **Soul Transfer Pac-Man** | You play as the ghosts. Pac-Man phases between bodies; you use BFS pathfinding to cut him off. |
| **Snake Classic** | The goal is to fill the board, not survive. Eating food permanently changes tiles. |
| **Sudoku Classic** | Automatically shows valid numbers for every empty cell, with a heat map for the hardest cells. |
| **Block Blaster** | Auto-aim activates when 90% of blocks are cleared, so you never watch the ball bounce endlessly. |
| **Block Blast (Ghost Edition)** | Ghost pieces fill empty cells but ignore filled ones, making placement forgiving and strategic. |
| **Match 3 (Powerup Fusion)** | Swap two powerups to fuse their effects into stronger combinations. |
